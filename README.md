# KaleiC

<p align="center">
  <img alt="Nix Powered" src="https://img.shields.io/badge/Nix-Powered-blue?logo=nixos" />

`kaleic` is a compiler implementing a toy language.
It is named after `kaleidoscope`, the name of the LLVM tutorial example.

Check out the project direction/documentation at [kalei.wiro.world](https://kalei.wiro.world).

The latest version of the compiler source code documentation is available as [rust-docs.kalei.wiro.world](https://rust-docs.kalei.wiro.world/kaleic/).
